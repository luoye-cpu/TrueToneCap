## 🎯 F4 静置唤醒深度分析

### 问题根源追踪

**代码位置**: `HdrCaptureWindow.cs:4258-4270`

```csharp
// _regionRefreshTimer 每 3s 全量 DetectWindows
if (!_regionRefreshTimer.IsActive) 
{
    _regionRefreshTimer.Start();
    // ... 检测窗口变化
}

// 未框选时 RequestRedraw
if (_currentRegion is null) 
{
    RequestRedraw(); // ← 触发整图重排
}
```

**可能原因**:
1. **窗口检测过于频繁** - EnumWindows 在后台线程跑
2. **静置重绘条件宽松** - 只要 `_currentRegion is null` 就重绘
3. **图集排版污染** - 悬停换窗触发 `_atlasScale=-1` → 全图重新布局

**实测印证**:
```log
14:17:51.473 [Debug] 渲染帧 #1
14:17:56.328 [Debug] 渲染帧 #11  (间隔≈4.8s)
14:17:56.484 [Debug] 渲染帧 #21  (间隔≈0.15s, 21 帧连发)
```

**观察**: 前 10 帧间隔~0.5s，后 11 帧在 0.15s 内爆发 → **批量刷新痕迹明显**

### 优化建议优先级

| 方案 | 预估收益 | 复杂度 | 推荐度 |
|------|---------|--------|--------|
| A. 增加静置判断（时间阈值+nop 移动） | 高 (↓60%) | 低 | ⭐⭐⭐⭐⭐ |
| B. 分页贴图延迟更新（异步排版） | 中 (↓30%) | 中 | ⭐⭐⭐⭐ |
| C. 分离 RenderCore 计时器 | 中 (精准度量) | 高 | ⭐⭐⭐ |
| D. 禁用未框选时的自动重绘 | 低 (安全相关) | 低 | ⭐⭐ |

**推荐路径**: 先实现 A + C，用数据驱动后续优化
