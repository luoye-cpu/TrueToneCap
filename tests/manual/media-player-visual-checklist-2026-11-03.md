# 动图产物的播放器肉眼抽验单（2026-11-03）

**这份单子要你回答的只有一件事**：四种动图格式录出来，在真实播放器里**能不能正常播、颜色对不对**。

自动化能判的那一层已经全绿了，不用重做（见下面「已知已绿」）。剩下的是必须眼睛看的——
播放器兼容性不是 ffprobe 能替的：文件结构合法、能解出帧，和在 Windows 照片 / 浏览器里
播不播得动、循环不循环、颜色有没有偏，是三件事。

对应台账：`docs/ledger/handoff-multimonitor-and-recording-2026-11-02.md` §9-3。

---

## 一、已知已绿（这些不必再看）

以下都已经用 ffprobe / 独立解码器验证过，出现问题时先怀疑播放器而不是产物：

| 格式 | 已验 | 证据 |
|---|---|---|
| 动画 WebP | 2 帧 4K 可解码；**ICCP 2100B 已嵌入**（画布 3840×2160 来自 VP8X） | 2026-11-03 实机 |
| 动画 AVIF | 5 帧可解码、零警告；nclx **bt2020 / iec61966-2-1 / matrix=0(gbr) / full-range** 全部持久化 | 同上 |
| GIF | 2 帧可解码 | 同上 |
| APNG | 2 帧 `apng` 解码**零警告**；cICP + iCCP + acTL 三个 chunk 齐 | 同上 |
| 回退链路 | AVIF 超时 → 首帧 16-bit PNG（sBIT=8 + cICP/iCCP）+ 降级提示 | 同上 |

## 二、怎么造出四份样张

一次只测**一个格式**（改完格式再录下一次）。

1. 起产品 → 左侧导航「截图与录制」→ 滚到「动图录制」卡片。
2. **格式**：先选 `GIF`。其余三份重复本流程时依次改成 `APNG` / `动画 AVIF` / `动画 WebP`。
3. **帧率** `15 fps`，**最大时长** `15 秒`（够录 5 秒，又不会到点自动收尾）。
4. **ffmpeg 路径**留空即可（本机 `C:\PLAN\FFmpeg\ffmpeg.exe` 已在 PATH 里，日志会打印
   `FfmpegLocator: ffmpeg 就绪: …`）。
5. 点「保存」。
6. 按 `Ctrl+Shift+G` 开始录制 → 数到约 5 秒 → 再按一次 `Ctrl+Shift+G` 停止。
7. 等状态栏提示「🎬 录制已保存」，到输出目录取产物（文件名带毫秒时间戳）。
8. 换下一个格式，重复 2–7。

> 提示：录制读的是 SDR 8-bit 池，所以四份产物都是 SDR；不要拿 HDR 期待去判它们。

## 三、逐格式 × 逐播放器（在主表里打勾）

播放器列按本机实际安装填；没装的写「未装」，不要空着。

| 格式 | Windows 照片 | Edge | Chrome | 系统默认关联程序 |
|---|---|---|---|---|
| GIF | ⬜ | ⬜ | ⬜ | ⬜ |
| APNG | ⬜ | ⬜ | ⬜ | ⬜ |
| 动画 AVIF | ⬜ | ⬜ | ⬜ | ⬜ |
| 动画 WebP | ⬜ | ⬜ | ⬜ | ⬜ |

**每格判定为「✅ 通过」需要同时满足**：

1. **动起来**：能看出画面在动，不是停在一张静帧。
2. **帧数量级对**：约 5 秒 × 15 fps ≈ **75 帧**，允许 ±1 帧。明显只有个位数帧 =
   录制段丢帧，记下来。
3. **自动循环**：播到结尾会自己从头再播（这是 §9-3 点名未验的 `-loop` 语义）。
   不循环不算致命，但要记：**哪个播放器不循环**。
4. **首末帧完整**：没有"末尾缺一块""第一帧是黑屏"。
5. **颜色没明显跑偏**：见下一节的逐格式期望。
6. **无绿边/黑边/撕裂**，画面尺寸与截图区域一致。

## 四、每格具体看什么（颜色期望按格式不同）

| 格式 | 产物带的声明 | 肉眼期望 |
|---|---|---|
| GIF | **无任何色彩声明**（格式限制；像素已烘焙到目标色域） | 颜色应接近原截图。若明显发灰或过饱和，是烘焙环节的问题，不是声明缺失 |
| APNG | cICP + iCCP 都在 | 支持色彩管理的查看器里颜色应与原截图一致 |
| 动画 AVIF | 只有 **nclx**（无 ICC prof box——ffmpeg muxer 限制，见下「已知边界」） | 桌面内容通常是 Rec.709/sRGB，nclx 一致时看不出差别 |
| 动画 WebP | **ICCP 已嵌入** | 支持 ICCP 的查看器里颜色应准 |

> **「看不到色彩差异」就是通过。** 本机是 HDR 主屏 + SDR 副屏，如果录的是广色域内容，
> 在 sRGB 查看器里出现轻微变化属于预期；明显偏色才记。

## 五、已知边界（这些**不是**缺陷，别记成 bug）

1. **动画 AVIF 没有 prof(ICC) box** —— ffmpeg muxer 限制，nclx 通道已够用（台账 §12 记档）。
2. **GIF 没有声明通道** —— 格式限制，像素已烘焙。
3. **回退单帧 PNG 是 16-bit 容器但实际精度 8-bit** —— sBIT=8 如实声明，不是撒谎。
4. **某些播放器不认 APNG** —— 老版本「Windows 照片」可能只显示第一帧。这是播放器覆盖问题，
   记下来即可，不改产物。
